# Уроки Садии — Android илова

Ичида: 1–4-синф дастури (математика, мантиқ, инглиз тили, рус тили), кунма-кун дарслар, кунига 60 дақиқа чеклов, ота-она бўлими. Илова интернетсиз ишлайди, натижалар телефонда сақланади.

## APK олишнинг 2 йўли

### 1-йўл: GitHub орқали (компьютерга ҳеч нарса ўрнатмасдан)
1. github.com да бепул аккаунт очинг ва янги repository яратинг (масалан, `sadiya-darslar`).
2. "Add file → Upload files" орқали шу папкадаги барча файлларни юкланг (`.github` папкаси ҳам бўлсин).
3. "Actions" бўлимида "Build APK" иши ўзи бошланади (5–7 дақиқа).
4. Тугагач, ишни очинг ва пастда **Sadiya-darslar-apk** файлини юклаб олинг. Ичида `app-debug.apk` бор.
5. APK ни телефонга ўтказинг ва очинг. Телефон "номаълум манбалардан ўрнатиш"га рухсат сўрайди — рухсат беринг.

### 2-йўл: Android Studio орқали
1. Android Studio ни ўрнатинг (developer.android.com/studio).
2. "Open" → шу `android` папкасини танланг.
3. Menu: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Тайёр файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Инглиз сўзларини эшитиш
Илова телефоннинг "Text-to-speech" хизматидан фойдаланади. Агар овоз чиқмаса: Созламалар → Тил ва киритиш → Text-to-speech → Google ва English (UK ёки US) тилини юклаб олинг.

## Дастурни янгилаш
Дарслар `app/src/main/assets/index.html` файлида. Уни алмаштириб, APK ни қайта йиғинг.
